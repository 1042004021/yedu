# 生图模型目录说明

## 1. 适用版本

| App | 包名 | 版本 |
|-----|------|------|
| Tavern Dream | `com.taverndream` | 0.10.3 / 32 |
| 夜读 | `com.taverndream.yedu` | 1.0.0 / 1 |

两个 App 使用同一套模型目录约定。把模型放到公共存储后，两个 App 都能读取，不需要 adb 推送到 `/data/data/...`。

## 2. App 会扫描的目录

按顺序扫描，找到第一个包含 `unet.bin` 或 `unet.mnn` 的 `<模型ID>` 目录后使用：

1. App 内部：`/data/data/<包名>/files/models/<模型ID>/`
2. App 专属外部目录：`/storage/emulated/0/Android/data/<包名>/files/models/<模型ID>/`
3. `/storage/emulated/0/Yedu/models/<模型ID>/`
4. `/storage/emulated/0/Galgame/models/<模型ID>/`
5. `/storage/emulated/0/TavernDream/models/<模型ID>/`
6. `/storage/emulated/0/Download/Yedu/models/<模型ID>/`
7. `/storage/emulated/0/Download/Galgame/models/<模型ID>/`
8. `/storage/emulated/0/Download/TavernDream/models/<模型ID>/`
9. 设置页「自定义父目录」里填的目录：`<自定义父目录>/<模型ID>/`

推荐使用 **`/storage/emulated/0/Download/Yedu/models/`**，文件管理器最容易找到。

## 3. 目录结构

以 RealVisXL V5 为例，模型 ID 是 `realvisxl`：

```text
/storage/emulated/0/Download/Yedu/models/
└── realvisxl/
    ├── clip.bin
    ├── unet.bin
    ├── vae_decoder.bin
    ├── tokenizer.json
    ├── vae_encoder.bin   （如果有）
    └── ...
```

SD1.5 模型把下载的 zip **完整解压**，确保 `unet.bin` 直接位于 `models/<模型ID>/` 下；不要多套一层 `realvisxl/realvisxl/`。

CPU 模型的标记文件是 `unet.mnn`，目录结构同理。

## 4. 权限

### Android 11 及以上

公共存储目录需要「所有文件访问」：

1. 打开 App → 设置 → 生图模型目录。
2. 点「授权所有文件访问」。
3. 在系统页面打开该 App 的「所有文件访问」开关。
4. 回到 App，点「刷新目录」。

### Android 10 及以下

点「授权存储读取」，允许读取存储即可。

如果系统不允许访问公共目录，可改用 App 专属外部目录：

```text
/storage/emulated/0/Android/data/com.taverndream.yedu/files/models/<模型ID>/
/storage/emulated/0/Android/data/com.taverndream/files/models/<模型ID>/
```

## 6. 常见问题

- **设置页显示未下载**：检查 `<模型ID>/unet.bin` 是否存在；`unet.bin` 是判定标记。
- **显示已下载但引擎启动失败**：模型文件不完整，重新完整解压；删除后重试。
- **两个 App 能共用吗**：可以，放到 `Download/Yedu/models`、`Download/Galgame/models` 或 `Download/TavernDream/models` 任一公共目录，两个 App 都会扫描。
- **删除模型**：设置页删除会删除所有扫描目录里的同名模型；如果不想让 App 删除公共目录，请手动管理并在删除前移走。
- **超分模型**：目前仍从 App 内部下载，暂不参与多目录扫描。
