## 2. 任务信息

### 2.1 任务名称

单张 CG 重绘与提示词编辑

### 2.2 任务描述

- 在画廊中为每张 CG 提供提示词编辑入口，已生成和未生成图片都可以编辑。
- 保存提示词后立即重绘该张 CG，不等待其他图片。
- 修改后的提示词写回当前剧本 `script.json`，切换剧本后仍然保留。
- 重绘时删除旧图、清空当前背景/封面引用；新图生成后恢复展示并刷新首页封面。

### 2.3 拆分方式

按功能点拆分为单任务：画廊编辑入口、提示词持久化、单张优先重绘。

## 3. 技术方案（如有）

### 3.1 实现思路

- 画廊卡片右下角增加编辑按钮，未生成卡片也可进入提示词弹窗。
- 全屏预览增加“编辑提示词并重绘”入口。
- `GalgameViewModel.regenerateImage(imageId, prompt)`：
  - 校验提示词非空并更新内存中的图片规格；
  - 写回当前剧本 JSON，同时刷新剧本库中的内存剧本对象；
  - 删除旧图片和路径映射，清空当前背景/封面引用；
  - 调用 `startImageWorker(priorityImageId = imageId)`，把该图片排到待生成队列首位。
- 生成完成后沿用现有逻辑更新画廊、播放背景和首页封面。

## 9. 实现索引（任务完成时必填）

### 9.1 最终实现方案

- `GalgameViewModel.regenerateImage` 负责提示词校验、剧本更新、JSON 落盘、旧图清理和单张优先重绘。
- `startImageWorker` 增加 `priorityImageId` 参数，用稳定排序把目标图片放到待生成队列首位；完成后继续原队列。
- 提示词同时写入当前剧本 JSON 和 `library` 中的内存剧本，避免切回剧本时被旧对象覆盖。
- 画廊 `GalleryCard` 增加编辑图标；`PromptEditDialog` 提供多行提示词编辑、空值禁用和“保存并重绘”。
- 画廊全屏预览增加“编辑提示词并重绘”入口，关闭预览后直接打开编辑弹窗。
- 删除旧图时同步清空当前背景和首页封面引用；生成完成后由现有 worker 更新路径、背景和封面。
